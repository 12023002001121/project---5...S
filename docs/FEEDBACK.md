# Feedback Documentation

## What We Heard

During the Level 5 testing phase, we collected feedback from numerous users on the Preprod/Testnet environment. The key themes from this feedback were:

1. **Transaction Times:** Some users noted that the UI did not clearly indicate when a transaction was pending, leading them to click multiple times.
2. **Wallet Connection:** A few testers found the wallet connection process confusing, especially when switching between different testnet wallets.
3. **Error Messages:** Error messages were sometimes too technical and didn't offer a clear path to resolution.
4. **Navigation:** The dashboard layout was slightly cluttered on mobile devices.
5. **Onboarding:** The onboarding flow could be streamlined by combining a few steps.
